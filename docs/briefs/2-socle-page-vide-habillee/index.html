Socle : la page vide mais habillée

Le site hommage à Faker n'existait pas encore. Il a maintenant sa page d'accueil en rouge, noir et or, prête à recevoir le Parcours, le Palmarès et les Moments mythiques.

Décision attendue

Merger la pull request pour poser le socle du site. Relisez la phrase d'accroche et la Mention site de fan : je les ai rédigées moi-même.

Risque

Faible

Avant / après

Avant

Le projet ne contenait aucune page : il n'y avait rien à ouvrir.

→

Après

Une page d'accueil en français. Captures dans le dossier du brief : apres-page-ordinateur.png et apres-page-telephone.png (360 px).

Ce qui change

  1. La page s'ouvre sur le nom de Faker en très grand, son surnom et une phrase d'accroche
  2. Le style sombre rouge, noir et or est posé une fois pour toute la page
  3. La Mention site de fan s'affiche en bas de page
  4. La page tient sur un téléphone de 360 px de large, sans défiler de côté
  5. Netlify sait comment fabriquer et publier le site

RelectureDeux tours de relecture indépendante : six remarques corrigées. Quelques avis mineurs restent, listés dans la pull request.

RisquePremier socle d'un site statique : rien d'existant ne change, ni données ni comptes. Annuler la pull request suffit.

Choix effectués

Le site utilise la dernière version d'Astro, l'outil qui fabrique les pages, plutôt qu'une version plus ancienne. L'ancienne avait des failles de sécurité connues. La contrepartie : il faut au moins la version 22.23.4 de Node, le moteur qui fait tourner Astro. GitHub et Netlify prennent normalement la plus récente, mais il faut le vérifier au premier passage. Les polices sont celles déjà installées sur l'appareil du visiteur : rien à télécharger, la page s'ouvre plus vite. En contrepartie, le titre change un peu d'allure d'un téléphone à l'autre.

Pour l'essayer

Dans le dossier du ticket, lancez « npm ci » puis « npm run dev », et ouvrez localhost:4321. Réduisez la fenêtre à la largeur d'un téléphone : « FAKER » tient sur une ligne et rien ne défile de côté.
